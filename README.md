## 🎙️ AI Ovozli E'lonlar (Text-to-Speech)

Loyihaga **Microsoft Edge Neural AI** dvigateli to'liq integratsiya qilindi:

1. **🌟 100% BEPUL va API Kalitsiz O'zbekcha AI Ovozlar:**
   - 👩 **Madina** — O'zbek tilidagi rasmiy, muloyim va mayin ayol ovozi (Studiya sifati, defolt qilib belgilandi).
   - 👨 **Sardor** — O'zbek tilidagi aniq, jiddiy va ravon erkak ovozi.
   - **Afzalligi:** Hech qanday to'lov, hisob ochish yoki API kalit talab qilinmaydi!
2. **🔑 Narakeet AI integratsiyasi:**
   - 👩 **Zulfiya** va 👨 **Shavkat** ovozlaridan foydalanish imkoniyati ham saqlab qolingan.
3. **Qo'ng'iroq va E'lonlar Ketma-ketligi:**
   - **Kirishda:** `[Chime]` ➔ `[Maktab qo'ng'irog'i]` ➔ `[AI e'loni: "1-soat boshlandi"]`
   - **Tanaffusda:** `[Maktab qo'ng'irog'i]` ➔ `[AI e'loni: "1-soat tugadi. 10 daqiqalik tanaffus"]`
   - **Tushlikda:** `[Maktab qo'ng'irog'i]` ➔ `[AI e'loni: "4-soat tugadi. Tushlik vaqti boshlandi. Yoqimli ishtaha!"]`
   - **To'lma choyda:** `[Maktab qo'ng'irog'i]` ➔ `[AI e'loni: "7-soat tugadi. To'lma choy vaqti boshlandi."]`
   - **Uyga vazifa soatida:** `[Chime]` ➔ `[Qo'ng'iroq]` ➔ `[AI e'loni: "Uyga vazifa va mustaqil ta'lim soati boshlandi."]`
4. **Tayyor MP3 Kesh:**
   - Barcha 16 ta kunlik dars va tanaffus e'lonlari allaqachon generatsiya qilinib, `audio/tts_cache/` papkasiga saqlab qo'yildi.
   - Tizim internet bo'lmasa ham 0 millisekundda bevosita mahalliy diskdan ishlaydi!
